02 / Add a tool

Ship one in three steps.

  1. Build it static

    One folder, plain HTML/CSS/JS. Put it at tools/<slug>/index.html.

  2. Register it

    Add one entry to the TOOLS list in index.html: name, summary, category, status.

  3. Push to main

    GitHub Pages publishes it. The card appears here in about a minute.
